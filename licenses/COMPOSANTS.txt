Microsoft.Web.WebView2 SDK 1.0.4258.31 : licence Microsoft ci-jointe.
Microsoft Edge WebView2 Runtime fixe 154.0.4258.62 x64 : runtime embarqué
dans wad/runtime/webview2 ; conditions Microsoft dans WebView2-FixedRuntime-LICENSE.html.
Tous les fichiers et avis tiers du runtime sont conservés sans modification.
La commande show_third_party_software_licenses.bat fournie par Microsoft et
les sous-dossiers du runtime donnent accès aux notices de ses composants.

L’interface utilise ce runtime fixe local ; aucun installateur WebView2 ne se
lance et aucune mise à jour du runtime ne se télécharge au démarrage.
Le navigateur Edge ou Chrome utilisé pour la connexion à GLPI reste celui
installé sur le poste. Il n’est pas redistribué avec le pilote Playwright.

Le Chromium utilisé pendant les tests sous Linux ne fait pas partie du pack.
GLPI Pilot est un outil indépendant et n’est pas un produit officiel GLPI.

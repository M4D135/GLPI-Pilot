# Patch des sites GLPI Pilot — v1

Le lanceur Admin produit deux fichiers dans un nouveau sous-dossier : `GLPI-Pilot-Sites-v1.csv` et `GLPI-Pilot-Sites.sha256`. Après validation, le diffuseur dépose ces deux fichiers dans le dossier réseau de diffusion. Publier le CSV complet avant son empreinte, par renommage de fichiers temporaires ; les clients revérifient les octets avant l’application.

Le CSV UTF-8 conserve les colonnes complètes de l’export du référentiel, les identifiants stables des villes, sites et bâtiments, et leurs relations. Un élément absent reste présent sur les postes. Le comparatif montre les valeurs locales et les valeurs proposées ; une confirmation remplace les valeurs affichées et crée une sauvegarde JSON du référentiel précédent, réimportable par l’assistant de configuration.

Le format v1 réserve le préfixe `~glpi-text-v1:` pour protéger les cellules susceptibles d’être interprétées comme des formules par un tableur. Une cellule commençant par une apostrophe, une tabulation, un retour à la ligne ou, après des espaces/contrôles, par `=`, `+`, `-` ou `@`, est remplacée par ce préfixe suivi du Base64 canonique de son texte UTF-8. Une valeur littérale commençant déjà par ce préfixe est encodée elle aussi. Le lecteur décode une seule fois, sans exécuter de formule ; un encodage invalide est refusé. Les identifiants, en-têtes et autres valeurs ordinaires restent lisibles normalement.

Cet encodage préserve notamment les téléphones `+33…`, coordonnées négatives et apostrophes réelles, sans les confondre avec la protection habituelle d’un export CSV. Régénérer le patch depuis Admin après modification du référentiel ; un export CSV générique n’est pas un patch v1 garanti. Le fichier `.sha256` contient exactement une ligne au format `empreinte_SHA256`, deux espaces, puis `GLPI-Pilot-Sites-v1.csv`.

Les cellules `Alias`, `Exclusions` et `Fermetures` contiennent une liste JSON de chaînes, encodée en Base64 UTF-8 canonique après le préfixe `~glpi-list-v1:`. Même une liste vide possède cet encodage. Le lecteur conserve ainsi les limites exactes de chaque élément : un alias contenant `|` ou `;` reste un seul alias. Ce préfixe est réservé lui aussi ; s’il apparaît au début d’une valeur de texte ordinaire, l’exporteur protège cette valeur avec l’encodage texte. Les listes nulles, éléments nuls, encodages invalides et listes non marquées sont refusés. Un CSV générique avec des listes séparées par `|` ne remplace donc pas l’export de patch v1.

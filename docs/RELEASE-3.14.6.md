# GLPI Pilot 3.14.6 · Windows x64

Cette version ne change pas l’application : le code, l’interface et les contrôles sont ceux de la 3.14.5, menu **Réglages** façon Domenia compris.

Le pack embarque le rapport de vérification à jour, `wad/docs/Rapport-verification.txt`. Celui de la 3.14.5 s’arrêtait à la 3.10.2. Le nouveau rapport donne les contrôles, la qualification et la publication de la 3.14.5, puis renvoie aux notes de version pour les versions 3.11.0 à 3.14.4.

Dans les documents du pack, les liens vers des tags, commits et runs disparus pointent désormais vers les fichiers du dépôt, ou sont remplacés par un texte. Ces liens avaient disparu avec la recréation du dépôt le 8 novembre 2026, ou avec le retrait des anciennes releases le 12 novembre 2026.

Seule la dernière version reste publiée dans les Releases : la v3.14.5 est retirée après la publication de la 3.14.6.

Les documents Word/PDF de `DOC/` restent les instantanés 3.13.6.

Seul le pack **PROD-LIGHT** est destiné à la publication, sans runtime WebView2 embarqué. La qualification Windows du commit exact et l’inspection du ZIP original précèdent sa publication.

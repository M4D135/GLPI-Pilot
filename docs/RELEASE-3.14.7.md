# GLPI Pilot 3.14.7 · Windows x64

Cette version ne change pas l’application : le code, l’interface et les contrôles sont ceux de la 3.14.5 et de la 3.14.6.

Dans les documents du pack, les liens vers `REPRISE.md` de Domenia 2 visaient une branche `v2` qui n’existe plus. Ils pointent désormais vers la branche principale du dépôt Domenia. Deux liens visaient des commits de l’ancien dépôt Domenia, effacé lors de sa recréation le 9 novembre 2026 : ils sont remplacés par un texte. Les liens relatifs et les liens GitHub de la documentation ont tous été vérifiés.

Une seule version reste publiée dans les Releases : la v3.14.6 est retirée après la publication de la 3.14.7.

Les documents Word/PDF de `DOC/` restent les instantanés 3.13.6.

Seul le pack **PROD-LIGHT** est destiné à la publication, sans runtime WebView2 embarqué. La qualification Windows du commit exact et l’inspection du ZIP original précèdent sa publication.

# GLPI Pilot 3.3.1 — Mon espace

La rubrique **Ma journée** devient **Mon espace** pour représenter l’ensemble du travail personnel : file de tickets, notes, rappels, modèles et organisation des interventions.

Le nouveau nom apparaît dans la navigation, le titre de page, les raccourcis de l’accueil et de l’import en simulation, les boutons de retour, les notifications de rappels et la documentation d’utilisation. La palette de commandes reprend le titre de navigation.

L’identifiant interne de la rubrique est conservé : les favoris, la disposition du menu et les données personnelles continuent de pointer vers le même espace.

Les packs PROD et DEV sont publiés après réussite du workflow Windows et PostgreSQL sur le commit livré, avec les contrôles existants de navigation, de démarrage et de mise à jour. Le commit de chaque archive est indiqué dans `wad/version.json`.

Les fonctionnalités de pilotage et de simulation complète restent décrites dans les [notes 3.3.0](RELEASE-3.3.0.md).

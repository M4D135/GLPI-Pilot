CONFIGURATION DES SITES — GLPI-Pilot 3.3.2 ou ultérieur

INSTALLATION DANS UN LOGICIEL DÉJÀ PRÉSENT
1. Fermer complètement GLPI-Pilot, y compris une ancienne version ouverte.
2. Extraire ce ZIP dans le dossier qui contient GLPI-Pilot.exe.
   Le dossier wad du ZIP doit fusionner avec le dossier wad existant.
3. Vérifier la présence de wad\sites.csv à côté des autres fichiers du logiciel.
4. Ouvrir GLPI-Pilot.exe. L'import se fait automatiquement au démarrage.
5. Ouvrir Lieux et sites, puis sélectionner le type Site pour afficher la liste.

Le lanceur facultatif wad\support\INSTALL-SITES.cmd ouvre le même exécutable.
Ce complément contient les sites et les termes du tableau Paramétrage!B80:C106.
Il n'inclut pas GLPI-Pilot.exe ; le logiciel doit déjà être extrait sur le poste.
Le CSV est destiné à l'initialisation automatique dans wad.

26 SITES
Les noms et toutes les écritures reconnues sont conservés dans sites.csv.
Le moteur reconnaît automatiquement le nom du site, puis 36 variantes
supplémentaires distinctes après normalisation des accents et de la casse.

PROFIL UTILISATEUR
Les données sont enregistrées dans :
%LOCALAPPDATA%\GLPI-Pilot\settings.json
Elles restent modifiables dans Lieux et sites, type Site.
L'import sauvegarde les réglages existants avant leur modification.
Il n'est effectué qu'une fois par profil pour préserver les modifications
et suppressions réalisées ensuite dans l'application.
L'absence du fichier n'empêche pas le démarrage du logiciel.
